# Jev 多密钥并发、费用统计与线报记录筛选刷新

## 目标

提高新线报判断吞吐量，减少重复输入与不必要调用，让管理员看见 Jev 美元费用并便捷查看持续更新的处理记录。

## 用户已明确要求

- 支持多个 Jev API Key 并发调用；某个 Key 请求失败三次后禁用该 Key。
- 一条线报合理合并需求请求，例如抽纸与卸妆膏放在同一个 Jev 请求；核实这样是否节省费用。
- Jev 配置页面记录产生的费用，单位美元，价格以 Jev 官方文档为准。
- 线报记录页增加状态筛选，以及可启用的每五秒自动刷新按钮。

## 规划状态

用户已授权创建任务。正在核验当前批处理、队列、配置安全及列表接口，以及官方价格和用量协议。尚未修改产品代码或开始实施。

## 待厘清

- 三次失败指连续失败还是累计失败；是否将限流、超时及服务故障计入。
- 官方计费依据、响应实际用量及未知账单的展示方式。
- 当前请求是否已合并所有启用需求，以及提供方限制。

## 初步验收范围

- 多 Key 配置安全保存，禁用 Key 不继续分配请求，其余 Key 继续处理；既有单 Key 配置可迁移。
- 合并需求后每项独立关联结果，错误或缺失答案不当作命中，不重复通知。
- 美元费用有可追溯用量与价格依据，未知费用不能伪装为零或真实账单。
- 状态筛选覆盖现有记录状态；自动刷新每五秒执行，关闭后停止并保留筛选。
