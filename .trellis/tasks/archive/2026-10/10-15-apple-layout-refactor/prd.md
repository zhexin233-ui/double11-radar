# Apple 风格页面布局调整与重构规划

## 目标与用户决定

将现有线报管理后台统一重构为 Apple 官网式视觉：大标题、宽留白、克制配色与清晰的区块节奏，提高页面层级和阅读体验，并保留完整管理能力。

- 用户选择 B：Apple 官网式展示方向，接受单屏信息量减少的取舍。
- 用户选择 A：覆盖全站，分阶段实施。
- 本轮交付规划；仅在用户后续明确批准最新方案后进入实施。

## 背景与证据

- 当前为 Next.js App Router，服务端布局负责会话保护，客户端负责交互；共享样式位于 `src/app/globals.css`，没有 UI 库或状态库。
- 导航与正文分别限宽 1080px / 960px（`src/app/globals.css:38`、`:95`）；导航详情匹配与响应式存在改进空间（`src/components/AdminNav.tsx:39`；`src/app/globals.css:183`）。
- Jev 页聚合连接、密钥池、费用账本和试判（`src/app/(admin)/jev/page.tsx:622`、`:667`、`:684`），需要按任务重组内容。
- 页面地图、其他代码锚点与业务保护清单见 `research/current-ui.md`；官方参考原则与检索边界见 `research/apple-reference.md`。

## 范围

登录 `/login`；运行状态 `/status`；记录 `/bulletins` 与详情 `/bulletins/[id]`；需求 `/needs`；频道 `/channels`；Jev `/jev`；推送 `/push`。同时覆盖共享导航、标题、区块、表单、表格、反馈与响应式样式。

## 需求

| 编号 | 需求 |
| --- | --- |
| R1 | 全站采用同一套 Apple 官网式排版、留白、色彩、圆角和区块节奏，状态与操作保持易辨识；不以口号或无业务意义的装饰占据主要内容区 |
| R2 | 顶部导航与页面内容统一对齐；记录详情归属记录入口；主标题、说明和主操作有稳定的位置，窄屏仍能访问所有导航 |
| R3 | 状态页优先呈现真实健康与异常；记录页清晰区分筛选、数据与分页；详情区分原文、判断与投递 |
| R4 | Jev 按连接与调度、密钥、费用、试判分区；需求、频道、推送和登录使用一致的标题、输入与反馈规范；次要说明可渐进展开，关键错误与计费/凭据提示保持可见 |
| R5 | 从 375px 窄屏到 1440px 桌面可用，整页无横向溢出；宽表局部滚动，正文和主要操作不被裁切；放大文字后可阅读操作 |
| R6 | 提供可见键盘焦点、语义标题与表单标签；状态除颜色外有文字，加载/空/失败/保存/禁用态清晰且可感知 |
| R7 | 保留路由、权限、API、刷新并发与分页、表单保存和危险操作确认语义；凭据三态、价格/费用未知值、分类说明来源及投递重试边界不得因布局变化丢失 |
| R8 | 将重复的展示布局与样式整理成适度共享组件，保持服务端/客户端、服务端数据/表单状态边界；不引入第二套请求或状态机制 |

## 验收标准

| 编号 | 可观察结果 | 对应需求 |
| --- | --- | --- |
| AC1 | 全部八类页面在桌面与窄屏有截图记录；大标题、区块留白、色彩和导航视觉一致，表格/表单的阅读密度受控 | R1–R4 |
| AC2 | 六个管理入口、详情返回及退出可用；详情页激活记录导航，当前入口有 `aria-current`，键盘可完整走过导航 | R2、R6、R7 |
| AC3 | 375/768/1024/1440px 宽度下整页无横向溢出；长标题、URL、错误文案和多 Key 不遮挡操作，宽表仅自身滚动；200% 浏览器缩放可操作 | R5 |
| AC4 | 加载、无数据、API 失败、刷新失败保留旧数据、保存成功及忙碌禁用态均被检查；错误不被折叠说明隐藏，状态有文字且焦点可见 | R3、R4、R6 |
| AC5 | 用隔离测试数据验证筛选重置分页、分页与轮询、需求失焦保存、频道选择、Jev/推送保存、凭据三态及确认流程；记录所有通过/失败项，不使用生产凭据或真实推送 | R4、R7 |
| AC6 | 明确匹配/待确认/处理失败/没有匹配准确区分；程序说明、未知费用/价格、估算标识、Key 禁用原因及独立投递重试语义保留 | R3、R4、R7 |
| AC7 | `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm build` 通过；API 保持动态；组件重组不改变 API DTO、数据库或后台调度 | R7、R8 |

## 范围外与已知限制

- 不增加业务功能、改动后端/API/数据库、采集判断投递规则、认证方式或路由名称。
- 首期只做浅色主题；暗色主题、营销动效、大型图片、WebGL、完整 UI 库迁移不在本任务。
- 不部署，不用真实 Jev/Bark/飞书凭据做测试调用；测试与截图不得暴露明文凭据。
- 当前现状来自代码检查，尚无实屏基线；实施先补基线。现有 node 测试不提供 DOM/视觉保障，需补浏览器验收记录。
